# RE Webapp Factory — 현재 작업 방식 (As-Is)

> 이 문서는 하네스 도입 전, 사용자가 Claude·GPT 및 GitHub와 수동으로 웹앱을 제작·검토·배포했던 현재 작업 방식(As-Is)을 기록한다. 서비스의 목적과 기능을 정의한 `story-service.md`와는 별개의 문서다.

- **문서 상태:** 확정된 As-Is v1
- **작성일:** 2026-09-29
- **출처:** 사용자가 직접 설명한 11단계 작업 경험
- **상태 표기:** `확정` 사용자가 직접 말했거나 확인함 · `추정` 사실에서 유추했으며 확인되지 않음 · `후보` 현재 하고 있다는 사실은 없고 향후 관리 대상으로 검토할 것

---

## 1. 현재 작업 과정

| # | 문장 | 원래 단계 |
|---|---|---|
| S1 | **내가** 원하는 웹앱의 니즈와 완성 모습을 Claude·GPT에 자연어로 두서없이 **전달한다.** | 1 |
| S2 | **Claude·GPT가** 내 니즈를 해석하고 예상 산출물과 작업 방향에 대한 의견을 **준다.** | 2 |
| S3 | **내가** 의견을 검토한 뒤 작업을 **요청한다.** | 3 |
| S4 | **Claude·GPT가** 웹앱을 **만든다.** | 4 |
| S5 | **내가** 완성 산출물이 나올 때마다 폰트 위계·행간·자간·마진·패딩을 검토하고 수정을 **반복 요청한다.** | 5 |
| S6 | **내가** 산출물을 GitHub에 올려 달라고 요청한 뒤, GitHub Pages 브랜치를 직접 들어가 **설정한다.** | 6, 7 |
| S7 | **내가** 모바일에서 작동을 확인하며 문제 수정과 GitHub 커밋을 요청하고, 홈 화면에 추가한 뒤 아이콘이 없는 걸 발견해 아이콘 제작과 수정을 **반복 요청한다.** | 8, 9, 10, 11 |

> S7은 7문장 제한 때문에 모바일 검토와 홈 아이콘 검토를 한 문장으로 묶었다. 두 검토는 게이트에서 따로 관리한다(G4, G5).

---

## 2. 산출물·관리 대상

| # | 명사 | 구분 | 나온 문장 | 상태 |
|---|---|---|---|---|
| N1 | 웹앱 요구 설명 | 입력 산출물 | S1 | 확정 |
| N2 | AI의 산출물·작업 방향 제안 | 중간 산출물 | S2 | 확정 |
| N3 | 웹앱 산출물 | 핵심 산출물 | S4, S5 | 확정 |
| N4 | 디자인 QA 피드백 (폰트 위계·행간·자간·마진·패딩) | 검토 산출물 | S5 | 확정 |
| N5 | GitHub 저장소 | 관리 대상 | S6 | 확정 |
| N6 | GitHub Pages 설정 (브랜치) | 배포 설정 · 관리 대상 | S6 | 확정 |
| N7 | 모바일 QA 결과 (상단 고정·폰트·여백·효과 글꼴) | 검토 산출물 | S7 | 확정 |
| N8 | 커밋 또는 변경 기록 | 기록 | S7 | 확정 |
| N9 | 홈 화면 아이콘 | 핵심 산출물 | S7 | 확정 |
| N10 | 배포된 페이지 주소 | 관리 대상 | S6, S7 | 후보 (모바일에서 확인한 것과 URL을 따로 관리한 것은 다른 이야기) |
| N11 | 반복 수정 이력 | 기록 | S5, S7 | 후보 (현재 남기고 있다는 사실 없음, 향후 관리 후보) |

## 3. 게이트

| # | 게이트 | 유형 | 발생한 문제 | 문장 | 상태 |
|---|---|---|---|---|---|
| G1 | 작업 방향 승인 | 사용자 승인 게이트 | AI의 산출물·작업 방향 제안을 검토한 뒤 작업을 요청함 | S3 | 확정 |
| G2 | 디자인 검토 | 재작업 | 폰트 위계·행간·자간·마진·패딩이 항상 비좁아 수정이 불가피함. 완성 산출물이 나올 때마다 검토와 수정을 반복함 | S5 | 확정 |
| G3 | GitHub Pages 설정 | 번거로움 | 브랜치를 사용자가 직접 들어가서 설정해야 함 | S6 | 확정 |
| G4 | 모바일 검토 | 재작업 | 상단 고정 미작동, 폰트·여백 문제, 효과 글꼴 부재가 반복됨. 니즈를 다시 설명하고 수정을 반복함 | S7 | 확정 |
| G5 | 홈 아이콘 검토 | 누락 + 재작업 | 홈 화면에 추가한 뒤에야 아이콘 부재를 발견함. 아이콘 디자인이 마음에 들지 않아 수정을 반복함 | S7 | 확정 |
