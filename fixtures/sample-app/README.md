# RE Sample App

하네스 v1 검증용 샘플 앱이다. 현재 버전은 1.0.1이다.

- 메모를 입력하면 LocalStorage에 자동 저장하고, 새로고침 후 복구한다.
- 미리보기 영역은 `[data-sticky-preview]`로 상단 고정된다.
- design contract(`data-ui`·`data-type`)를 선언해 필드 그룹 간격·글자 역할·역할별 radius를 하네스가 검사한다.
- service worker 캐시 이름에 앱 버전을 넣는다. 새 버전은 설치 즉시 활성화되고, 이전 버전이 열려 있던 화면은 한 번 새로고침된다.

## 아이콘

현재 아이콘(`icons/`)은 **임시 아이콘**이다. 단색 사각형이며, 공개 배포 전 사용자 디자인 승인이 필요하다.
